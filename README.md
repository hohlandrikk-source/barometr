# Барометр рынка — дашборд активности конкурентов

Публичная страница: https://hohlandrikk-source.github.io/barometr/

- `index.html` — дашборд (фильтры: выпуск, даты, блок, компания, бренд, продукт, канал; выгрузка CSV).
- `select.html` — страница отбора новостей (работает только с ключом доступа редактора; данные берутся из приватного репозитория `barometr-admin`).
- `data/registry.json` — опубликованный реестр новостей. Обновляется еженедельно (чт, 15:00 МСК) после отбора.
- `data/img/` — картинки и раскадровки.
